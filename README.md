# mini-epg

EPG (Electronic Program Guide) service for the Brazil TV platform. Serves the channel
list, daily schedules, "now playing" and search to the set-top-box and web guide, and
stores user favorites.

Owner: Guide squad (Brazil). On-call: #guide-oncall.

## Run it

```bash
npm install
npm start            # http://localhost:3000  (PORT to override)
npm test             # unit/API tests (jest + supertest)
npm run test:e2e     # Playwright, needs `npx playwright install chromium` once
```

## API

| Method | Path | Notes |
|---|---|---|
| GET | `/channels` | sorted by channel number |
| GET | `/channels/:id/schedule?date=YYYY-MM-DD` | day = São Paulo calendar day |
| GET | `/now-playing` | optional `?at=<ISO>` to time-travel (handy for QA) |
| GET | `/search?q=` | channel names + programme titles, max 20 programmes |
| GET/POST/DELETE | `/users/:userId/favorites` | max 50 favorites per user. POST body `{ "channelId": "spesp" }` |

The web guide lives in `public/` (plain JS, no build step).

## Things you need to know (read this!)

- **Times are always São Paulo local** (`-03:00`). Brazil has no DST since 2019; don't add
  timezone libraries "just in case", product said no.
- **Ratings are ClassInd** (Classificação Indicativa): `L` = Livre (all ages), then
  `10`, `12`, `14`, `16`, `18`. Never show an `18` programme in the kids profile (that
  feature isn't built yet, but legal is asking).
- **The importer (`src/legacy/importer.js`) runs nightly** on epg-batch-01 and regenerates
  `data/schedule.json`. **Don't modify it.** It has business rules nobody wrote down —
  the prime-time boost, the overlap rules, the "(R)" rerun handling. Ask Marcus.
  (Marcus left in March. Good luck.)
- Favorites are in memory for now. Redis migration is "next quarter" since 2024.
- Demo data covers 2026-10-20 and 2026-10-21 only.

## Data

- `data/channels.json` — channel line-up (8 channels in the demo).
- `data/schedule.json` — programmes, generated by the importer.
- `data/sample-feed.xmltv.txt` — sample provider feed: `npm run import` writes `/tmp/schedule.out.json`.
